 SII - Sistema Integrado de Informação - Uíge

 Como testar

1. Clica em Code > Download ZIP e descompacta

2. Para testar o SISTEMA 2 - Hospitais:
   Abre: SII_Cadastro deUnidades hospitalares > GestãodeHospitaiseUnidades > GestãodeHospitaiseUnidades.slnx
   Clica Start no Visual Studio e regista 2 hospitais.

3. Para testar o SISTEMA 1 - Pacientes:
   Abre: SII_RegistrodePacientes > CadastrodePacienteseConsultas > CadastrodePacienteseConsultas.slnx
   Clica Start no Visual Studio e regista um paciente.
   O sistema vai mostrar os hospitais do Sistema 2.

A integração é feita pelo ficheiro hospitais.txt porque o sistema não tem uma base de dados...
